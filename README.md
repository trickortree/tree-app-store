# Tree App Store

Desktop app store / launcher for the trickortree apps. Windows, Electron,
auto-updating from GitHub Releases (same release flow as
[trickortree/treesim](https://github.com/trickortree/treesim)).

The app list is [apps.json](apps.json). Tree Lens is its own app in
[trickortree/tree-lens](https://github.com/trickortree/tree-lens) and is installed from here.

See [GUIDE.md](GUIDE.md) for how to edit apps, names and HTML, and how to push.

```
npm install
npm start
```
